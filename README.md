# ft_transcendence

웹에서 실행되는 멀티플레이어 Pong 서비스를 단계적으로 구현하는 프로젝트입니다.
이 저장소는 기능을 작은 책임 단위로 추가하고, 각 단계가 검증 가능한 상태를 유지하는 것을 목표로 합니다.

## 초기 개발 원칙

- 애플리케이션과 공유 패키지는 pnpm workspace 안에서 관리합니다.
- 브라우저, API, 데이터베이스 경계를 명시하고 경계 사이의 값은 계약으로 검증합니다.
- 비밀값과 로컬 실행 상태는 Git에 포함하지 않습니다.
- 자동 생성 파일과 lockfile을 제외한 변경은 한 커밋에 하나의 책임을 담습니다.
- 각 커밋은 가능한 범위에서 typecheck, test, build로 검증합니다.
- 아직 구현하지 않은 기능은 현재 제공되는 기능처럼 문서화하지 않습니다.

## 디렉터리 규약

- `apps/`: 실행 가능한 애플리케이션
- `packages/`: 애플리케이션이 공유하는 패키지
- `tests/`: 여러 패키지를 함께 검증하는 테스트와 실행 검사

구체적인 실행 방법과 시스템 구조는 해당 기능이 구현되는 시점에 함께 추가합니다.
